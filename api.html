AutoSuggestion Quiz API (0.1.0)

Download OpenAPI specification:Download

REST API for the AutoSuggestion Quiz platform — a tool that lets teachers create fill-in-the-blank coding problems and present students with AI-generated code suggestions to choose from.

Authentication

Most teacher-facing endpoints require a Bearer JWT in the Authorization header. Obtain a token via /auth/login (email + password) or /auth/otp/verify (Supabase OTP). Student-facing endpoints (starting a submission, autosaving, submitting) are public and require no authentication.

Roles

Role Description
teacher Can create, edit, delete problems and view/grade submissions
admin Same as teacher but can act on any problem, not just their own
student Implied; submission endpoints are unauthenticated

submissions

Student submission lifecycle

Start or resume a submission session

Public endpoint — no authentication required. Identifies the student by name.

  • If the student already has an open (unsubmitted) draft for this problem, that session is returned with has_draft: true and the saved code.
  • Otherwise a new session is created.
  • If the problem has a max_attempts limit and the student has reached it, returns 403.
