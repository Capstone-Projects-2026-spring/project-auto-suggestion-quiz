# General Requirements

* Devices: Hardware/software must be present in order for application usage.
  - OS: Windows 10/11, or macOS
  - Internet: Required for accessing the web application, AI suggestions, and code execution

* Technology: Programming languages, frameworks, API.
  - Language: Python(Front end), Javascript (Backend)
  - Backend Framework: FastAPI with Uvicorn
  - Frontend Framework: React
  - Code editor: Monaco Editor
  - Database: PostgreSQL (via psycopg2)
  - AI API: OpenAI API key for AI coding assistant and suggestion functionality
  - Compiler: Judge0 (Hosted on Rapid API)
  - Deployment: Render (backend + frontend hosting via render.yaml)
  - Testing: pytest with pytest-cov (backend), React Testing Library (frontend)
