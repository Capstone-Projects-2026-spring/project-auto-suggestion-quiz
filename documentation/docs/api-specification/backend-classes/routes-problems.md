# `routes_problems.py` — Problems Router

**Source file:** `backend/routes_problems.py`  
**Router prefix:** `/problems`  
**Tags:** `problems`

**Purpose:** Manages the full lifecycle of coding problems: creation, retrieval, editing, deletion, and manual grading of submissions. Write operations require a valid teacher or admin JWT. The access-code lookup (`GET /problems/access/{code}`) is public so students can load a problem without authenticating.

---

## Request / Response Models

### `SuggestionIn`

**Purpose:** Represents one suggestion to attach to a section when creating a problem. The `content` field is intentionally blank for AI-type suggestions and is filled in later by the AI generation step.

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `type` | `str` | ✅ | — | `"ai"` — generated by GPT; `"manual"` — teacher-written |
| `isCorrect` | `bool` | ✅ | — | Whether this suggestion is the correct answer |
| `content` | `str` | ❌ | `""` | The suggestion code; empty for `"ai"` type until generated |

---

### `SectionIn`

**Purpose:** Represents one logical chunk of a problem's solution, presented to the student as a fill-in step.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `order` | `int` | ✅ | 0-based position in the problem; sections are sorted by this value |
| `label` | `str` | ✅ | Student-facing instruction shown above the code block |
| `code` | `dict[str, Any]` | ✅ | Map of language → starter code; e.g. `{"python": "def foo():\n"}` |
| `suggestions` | `list[SuggestionIn]` | ❌ | Suggestions for this specific section |

---

### `TestCaseIn`

**Purpose:** Represents a single automated test case for evaluating student submissions.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `input` | `str` | `""` | Valid Python call expression, e.g. `most_frequent([1,2,2])` |
| `expected` | `str` | `""` | Expected return value as a string, e.g. `"2"` |
| `explanation` | `str` | `""` | Human-readable explanation shown to the student on test failure |

---

### `CreateProblemRequest`

**Purpose:** Carries all the data needed to create a new problem, including sections, suggestions, test cases, and behavioral settings.

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `title` | `str` | ✅ | — | Problem title |
| `description` | `str` | ✅ | — | Student-facing problem statement |
| `languages` | `list[str]` | ✅ | — | Ordered list of supported languages; first is treated as primary |
| `boilerplate` | `dict[str, str]` | ✅ | — | Per-language boilerplate shown before section code (usually `""`) |
| `sections` | `list[SectionIn]` | ✅ | — | 2–4 ordered solution steps |
| `testCases` | `list[TestCaseIn]` | ❌ | `[]` | Automated test cases |
| `timeLimitSeconds` | `int \| None` | ❌ | `None` | Student time limit; `None` = no limit |
| `maxSubmissions` | `int \| None` | ❌ | `None` | Max submissions per student; `None` = unlimited |
| `allowCopyPaste` | `bool` | ❌ | `True` | Whether copy/paste is allowed in the editor |
| `trackTabSwitching` | `bool` | ❌ | `False` | Whether to log when the student leaves the tab |

---

### `EditProblemRequest`

**Purpose:** Partial update request — only the fields provided are changed. All fields are optional.

| Field | Type | Description |
|-------|------|-------------|
| `title` | `str \| None` | New title |
| `description` | `str \| None` | New description |
| `timeLimitSeconds` | `int \| None` | New time limit (`None` removes the limit) |
| `maxSubmissions` | `int \| None` | New submission cap (`None` removes the cap) |
| `allowCopyPaste` | `bool \| None` | Toggle copy/paste |
| `trackTabSwitching` | `bool \| None` | Toggle tab-switch tracking |

---

### `GradeSubmissionRequest`

**Purpose:** Carries a manual grade (0–100) to assign to a specific student submission.

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| `session_id` | `int` | ✅ | Must reference a session that belongs to this problem |
| `grade` | `int` | ✅ | Must be between `0` and `100` inclusive |

## Helper Functions

### `_get_current_user`

```python
def _get_current_user(authorization: Optional[str]) -> dict
```

**Purpose:** Extracts and validates the JWT from the `Authorization: Bearer <token>` header. Used by every protected endpoint in this router.

**Pre-conditions:**
- `authorization` must be a string in the format `"Bearer <jwt>"`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `authorization` | `str \| None` | Value of the `Authorization` header |

**Returns:** `dict` — Decoded JWT payload with keys `user_id`, `email`, `role`.

**Exceptions thrown:**

| HTTP Status | Condition |
|-------------|-----------|
| `401` | Header is missing, not a Bearer token, or JWT is invalid/expired |

---

### `_generate_unique_access_code`

```python
def _generate_unique_access_code(cursor) -> str
```

**Purpose:** Randomly generates a 6-digit numeric code and retries up to 10 times until a code is found that does not already exist in the `problems` table.

**Pre-conditions:**
- `cursor` must be an open database cursor.

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `psycopg2.Cursor` | Open DB cursor for uniqueness checks |

**Returns:** `str` — A unique 6-digit string, e.g. `"482910"`.

**Exceptions thrown:**

| HTTP Status | Condition |
|-------------|-----------|
| `500` | 10 consecutive random codes were all already taken (extremely unlikely) |

---

### `_build_problem`

```python
def _build_problem(cursor, problem: dict) -> dict
```

**Purpose:** Constructs the full problem response dictionary from a raw `problems` table row. Fetches all related sections, suggestions, test cases, and submitted sessions in additional queries.

**Pre-conditions:**
- `cursor` must be an open database cursor with `RealDictCursor` factory.
- `problem` must be a row from the `problems` table.

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `psycopg2.Cursor` | Open DB cursor |
| `problem` | `dict` | A single row from the `problems` table |

**Returns:** `dict` — Fully assembled problem object including `sections`, `suggestions`, `test_cases`, and `submissions`.

**Exceptions thrown:** None directly; psycopg2 errors may propagate if the database connection drops mid-query.

## Route Handlers

### `get_teacher_problems`

```
GET /problems/
Authorization: Bearer <token>  (teacher or admin)
```

**Purpose:** Returns all problems created by the authenticated teacher, newest first. Admins receive all problems regardless of creator.

**Pre-conditions:**
- Valid JWT with role `"teacher"` or `"admin"`.

**Post-conditions:**
- Each problem in the response is fully built via `_build_problem`, including sections, suggestions, test cases, and submitted sessions.

**Parameters:** `Authorization` header (via FastAPI `Header` dependency).

**Returns:** `list[dict]` — List of fully-assembled problem objects.

**Exceptions thrown:**

| HTTP Status | Condition |
|-------------|-----------|
| `401` | Missing or invalid token |
| `403` | Role is not `"teacher"` or `"admin"` |

---

### `create_problem`

```
POST /problems/
Authorization: Bearer <token>  (teacher or admin)
```

**Purpose:** Creates a problem with all its sections, suggestions, and test cases inside a single database transaction. Rolls back the entire transaction if any insert fails. Returns the fully built problem object.

**Pre-conditions:**
- Valid JWT with role `"teacher"` or `"admin"`.
- `req.languages` must contain at least one entry.
- For `"manual"` suggestion type, blank `content` is silently skipped.

**Post-conditions:**
- One row inserted into `problems`, one per section into `sections`, one per suggestion into `suggestions`, one per test case into `test_cases`.
- A unique 6-digit `access_code` is generated and attached.
- The full problem is returned via `_build_problem`.

| Parameter | Type | Source | Description |
|-----------|------|--------|-------------|
| `req` | `CreateProblemRequest` | Request body | Full problem definition |
| `authorization` | `str \| None` | Header | Bearer JWT |

**Returns:** `dict` — Fully assembled problem object.

**Exceptions thrown:**

| HTTP Status | Condition |
|-------------|-----------|
| `401` | Missing or invalid token |
| `403` | Role is not `"teacher"` or `"admin"` |
| `500` | Could not generate a unique access code (extremely rare) |

---

### `edit_problem`

```
PATCH /problems/{problem_id}
Authorization: Bearer <token>  (teacher or admin)
```

**Purpose:** Partially updates a problem's metadata and behavioral settings. Only the fields present in the request body are modified.

**Pre-conditions:**
- Valid JWT with role `"teacher"` or `"admin"`.
- Teachers may only edit their own problems; admins may edit any.
- `problem_id` must reference an existing problem.

**Post-conditions:**
- Only the provided fields are updated; others are unchanged.
- Returns the updated problem via `_build_problem`.

| Parameter | Type | Source | Description |
|-----------|------|--------|-------------|
| `problem_id` | `int` | Path | ID of the problem to edit |
| `req` | `EditProblemRequest` | Request body | Fields to update |
| `authorization` | `str \| None` | Header | Bearer JWT |

**Returns:** `dict` — Updated problem object.

**Exceptions thrown:**

| HTTP Status | Condition |
|-------------|-----------|
| `401` | Missing or invalid token |
| `403` | Not the problem owner (teacher) or wrong role |
| `404` | Problem not found |

---

### `delete_problem`

```
DELETE /problems/{problem_id}
Authorization: Bearer <token>  (teacher or admin)
```

**Purpose:** Permanently deletes a problem. The database cascade removes all dependent sections, suggestions, sessions, and logs. **This action is irreversible.**

**Pre-conditions:**
- Valid JWT with role `"teacher"` or `"admin"`.
- Teachers may only delete their own problems.

**Post-conditions:**
- The problem and all related rows are removed.

| Parameter | Type | Source | Description |
|-----------|------|--------|-------------|
| `problem_id` | `int` | Path | ID of the problem to delete |
| `authorization` | `str \| None` | Header | Bearer JWT |

**Returns:** `None` (HTTP `204 No Content`).

**Exceptions thrown:**

| HTTP Status | Condition |
|-------------|-----------|
| `401` | Missing or invalid token |
| `403` | Not the problem owner or wrong role |
| `404` | Problem not found |

---

### `grade_submission`

```
POST /problems/{problem_id}/grade
Authorization: Bearer <token>  (teacher or admin)
```

**Purpose:** Assigns a manual 0–100 grade to a student's submission session. Stores the value by setting `score = grade` and `total = 100` in the `sessions` table, normalising it to a percentage.

**Pre-conditions:**
- Valid JWT with role `"teacher"` or `"admin"`.
- `req.grade` must be between 0 and 100 inclusive.
- The session must belong to the specified problem.

**Post-conditions:**
- `sessions.score` is updated to `req.grade`, `sessions.total` is set to `100`.

| Parameter | Type | Source | Description |
|-----------|------|--------|-------------|
| `problem_id` | `int` | Path | ID of the problem the session belongs to |
| `req` | `GradeSubmissionRequest` | Request body | Session ID and grade |
| `authorization` | `str \| None` | Header | Bearer JWT |

**Returns:** `dict` — `{"session_id": int, "grade": int}`

**Exceptions thrown:**

| HTTP Status | Condition |
|-------------|-----------|
| `400` | Grade is outside the 0–100 range |
| `401` | Missing or invalid token |
| `403` | Not the problem owner or wrong role |
| `404` | Problem not found or session does not belong to this problem |

---

### `get_problem_by_code`

```
GET /problems/access/{code}
(no authentication required)
```

**Purpose:** Allows students to load a problem using the 6-digit access code printed on their assignment. This is a public endpoint — no JWT is needed.

**Pre-conditions:**
- `code` must be exactly 6 numeric digits.

**Post-conditions:**
- Returns the full problem object (sections, suggestions, test cases). Submissions from other students are also included in the response but the student UI does not display them.

| Parameter | Type | Source | Description |
|-----------|------|--------|-------------|
| `code` | `str` | Path | 6-digit numeric access code |

**Returns:** `dict` — Fully assembled problem object via `_build_problem`.

**Exceptions thrown:**

| HTTP Status | Condition |
|-------------|-----------|
| `400` | `code` is not exactly 6 digits |
| `404` | No problem with that access code exists |
